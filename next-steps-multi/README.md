# next-steps-multi

답이 끝나면 입력창 위에 다음 프롬프트를 최대 3개 제안한다. 여러 개를 골라 한꺼번에 입력창에 넣을 수 있다.

```
next:
  1: ☑ 방금 쓴 테스트 돌리기
  2: ☐ 설정 화면에도 적용
  3: ☑ 커밋
  0: 2개 입력창에 넣기
```

빈 입력창에서 `1` `2` `3` 을 누르면 체크가 켜지고 꺼진다. `0` 을 누르면 체크한 것들이 입력창에 들어간다. 하나면 그대로, 여럿이면 번호를 붙인다. 체크한 게 없을 때 `0` 은 목록을 닫는다. 맨 위 제안은 입력창의 흐린 글씨로도 떠서 `Tab` 으로 받을 수 있다.

스스로 보내는 일은 없다. 입력창에 넣기만 하고, 고쳐서 엔터를 누르는 건 사람이다.

## 원본과 다른 점

[`next-steps`](https://github.com/anthropics/claude-plugins-community/tree/main/next-steps) 1.0.0 (Thariq Shihipar) 의 `hooks/register.tsx` 를 고쳤다.

- 숫자를 누르면 그 제안 하나가 바로 입력창에 들어가던 것을, 체크만 하도록 바꿨다
- `0` 이 닫기만 하던 것을, 체크한 게 있으면 한꺼번에 입력창에 넣도록 바꿨다
- 체크 상태(`picked`)와 그것을 다루는 `toggle`, `joined` 를 더했다

제안을 만드는 방식(세션을 분기해 묻기, 스킬·슬래시 명령 제안, 제어 문자 걸러 내기)과 설정 항목은 원본 그대로다.

여러 개를 고르면 번호가 붙으므로, 그 안에 슬래시 명령 제안이 섞여 있으면 명령으로 실행되지 않는다.
