# coach-on-call

`코치 <대충 쓴 말>` 로 부를 때만 프롬프트를 다듬어 준다. 뭘 어떻게 적어야 할지 모를 때 쓴다.

```
코치 로그인 그거 좀 고쳐
```

작은 모델이 최근 대화 6턴을 보고 "그거"가 무엇인지 채워 선명한 프롬프트를 만든다. 그다음 고른다.

- **다듬은 걸로 보내기**
- **내 말 그대로 보내기**: `코치` 를 뗀 나머지를 보낸다
- **고쳐서 보내기**: 다듬은 것을 입력창에 넣는다. 고친 뒤 엔터

`코치` 로 시작하지 않는 프롬프트는 건드리지 않는다. 스스로 보내는 일은 없다.

## 원본과 다른 점

[`prompt-coach`](https://github.com/mishgoldenberg/claude-mods) 0.1.2 (Michael Goldenberg, MIT) 의 `hooks/register.tsx` 를 고쳤다.

- 보내는 프롬프트마다 검토하던 것을 `코치` 로 부를 때만 동작하게 바꿨다
- 켜고 끄는 `/coach` 명령과 설정 항목(`enabled`, `model`, `minChars`)을 없앴다
- "고칠 필요가 있는지" 판단하지 않고 항상 다듬은 안을 낸다. 그에 맞춰 검토 지시문을 다시 썼다
- 다듬지 못했거나 창을 닫으면 아무것도 보내지 않고 적은 말을 입력창에 돌려놓는다
- 세션 폴더 경로에 `04note` 가 있으면 끼어들지 않는다. 내 볼트에서는 "코치"가 다른 스킬을 부르는 말이라서다. 필요 없으면 `isVault` 를 지운다
- 화면 문구를 한국어로 바꿨다
